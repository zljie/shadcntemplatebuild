# 共享业务表单：默认方案与后续确认

本任务按 2026-10-01 用户提前批准执行。上一任务已核实并提交为 `2a6e4c7`；原 `.gitignore` 改动保留。此任务不推送，不覆盖此前导出的工程。

## 本轮默认方案

- 在已有 Runtime 中增加会话内记录状态；同一套 Dialog 表单服务图书、用户的新增与编辑。复用现有 Button、Input、原生 select、主题和工程导出。无新增依赖。
- 在 `listDetail.fields` 上声明默认值、必填、长度、数值范围、整数及枚举；`listDetail.form` 引用可编辑字段，并声明已注册的 `record.create` / `record.update`。不接收代码、URL 或自定义执行器。
- 图书：书名、作者、分类必填，库存为 0–100000 的整数；分类使用现有示例枚举。借阅状态只读，新增默认“可借阅”，编辑保留原值，不根据库存推导借还书状态。
- 用户：姓名、账号、角色、启用状态必填；角色为管理员／馆员／读者／审计员；启用状态为启用／停用，新增默认启用。不生成密码。
- 使用书名／账号作为各自模拟集合的唯一字段。重复值产生可重复的提交失败，保留输入。书名唯一仅是演示约束，不视为真实业务规则。
- 模拟提交有短暂异步等待；提交期间禁用提交、取消和关闭，防止取消后落库。每次操作有会话内幂等标识。成功关闭表单并提示，列表和已打开详情同步更新。
- 刷新、重新导入 DSL 或切换页面配置恢复示例数据。记录操作不写回 DSL，不进入编辑器撤销／重做历史。图书、用户集合由各自 Runtime 会话隔离。

`src/runtime/data.ts`、新增共享记录契约／模拟适配文件、`src/runtime/components.tsx`、`src/runtime/styles.css`、`src/core/schema.ts`、`src/core/validation.ts`、`src/core/registry.ts`、`src/core/page-protocol.ts`、`src/core/export-project.ts`；两份示例 DSL、必要测试、浏览器重跑脚本与验收说明。复用现有 Renderer、Generator 和 MCP 工具入口。

## 可观察验收

1. 自动检查：合法配置通过；未知动作、错误字段、非法枚举／范围和绕过界面的提交被拒绝；重复操作幂等、取消不写入、集合隔离。
2. 实际 AI 客户端：读取 MCP 组件与更新协议，生成两份 DSL，调用校验及导出；保留原始 MCP 记录。
3. 编辑器和仓库外工程：导入、表单默认值、回填、字段错误、失败保留输入、重复点击、新增后的搜索／筛选、编辑后的详情同步、取消／关闭、键盘焦点和刷新行为；比较共享源码和样式。
4. 回归：原资源中心、槽位、撤销重做、DSL 往返、MCP 和独立构建。
